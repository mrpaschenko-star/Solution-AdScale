## Ключевые допущения

- 18 000 RPS — цель трёхмесячного этапа; 50 000 RPS — самостоятельная годовая цель. Она выше простого удвоения текущих 15 000 RPS.
- Для текущего трафика промежуточный критерий — P95 ≤ 100 мс. Для новой DSP действует отдельное ограничение 80 мс. Выполнение первого критерия не доказывает готовность к интеграции.
- Точная семантика SLA партнёра, профиль событий и допустимая задержка обновления кампаний требуют согласования. Рабочие значения и условия запуска приведены в Drivers.md.
- Производительность и отказоустойчивость являются проектными целями, а не результатами измерений. Доступа к коду, трассам и инфраструктуре AdScale нет.
- Термин «DSP-партнёр» и направление OpenRTB-запросов сохранены из задания. Коммерческую роль AdScale и события, по которым происходит списание, нужно уточнить по контракту.
